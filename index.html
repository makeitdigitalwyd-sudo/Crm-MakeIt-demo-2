Multi-Device Cloud Sync

Sync customer records across your phone and laptop.

Automatic Cloud Database Local Mode (Not Connected)

Connecting a free Firebase database allows phone & laptop to sync automatically.

How to get your free Cloud Database URL in 2 minutes →
  1. Go to console.firebase.google.com and create a free project.
  2. Click Build → Realtime Database → Create Database.
  3. Choose Start in test mode so your devices can read/write.
  4. Copy your database URL and append /makeit_crm.json (e.g. https://my-app-default-rtdb.firebaseio.com/makeit_crm.json).
  5. Paste it above on your laptop and phone. Both devices will now auto-sync live!
